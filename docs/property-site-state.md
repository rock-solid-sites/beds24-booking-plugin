# Property Site State

Per-site record of current stack and any deviation from the
project's standard stack (Twenty Twenty-Five parent + custom
child theme + core Gutenberg blocks only, per
wordpress-setup.md).

The project covers five sites total: one landing page (the
umbrella domain) and four property sites that live as
subdirectories of the landing page's domain.

## Trip'N'Hostel Landing Page

- **Role:** Umbrella domain homepage. Sits above the four
  property sites; each property lives in a subdirectory.
- **Status:** Design phase. No development started.
- **Intended stack:** Project standard (Twenty Twenty-Five
  parent + custom child theme + core Gutenberg blocks).
- **Booking plugin:** Not installed. The landing page is not
  a property; it doesn't host bookings directly.
- **Per-site handoff document:** [to be created in tripn-sites
  during design phase]

## Chill Zone

- **Role:** Property site.
- **Status:** Site complete; booking page is the active work
  surface for the booking plugin V1 build.
- **Stack:** Hand-built. Kadence theme + Kadence Blocks +
  Kadence Starter Templates.
- **Project-stack alignment:** Predates the project's
  standardization. Grandfathered.
- **Future intent:** Potential redesign on the project's
  standard stack after the rest of the project (other three
  property sites + landing page + plugin V1) is successfully
  launched. Not scheduled.
- **Practical implication for current work:** Frontend work on
  the booking page may encounter Kadence-specific CSS or block
  markup in surrounding page elements. The booking plugin's
  own block is independent of Kadence, but visual context
  around the block is Kadence-rendered.
