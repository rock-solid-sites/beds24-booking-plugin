# docs/reference — Predecessor project reference files

The three files in this directory (`booking-widget.js`, `beds24-iframe-helper.js`,
`CSS-base.css`) are ported from the predecessor project
[TripN-Chill-Zone/booking-page](https://github.com/TripN-Chill-Zone/booking-page)
at the archived tag `archived-2026-05-07`. They are kept here as visual and
pattern reference — to preserve the design decisions, DOM knowledge, and
interaction patterns accumulated in that project — and are not active plugin
code. They are not loaded, enqueued, or referenced by any file in this plugin.
